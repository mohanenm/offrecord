# Your own evaluation set

This folder holds fake transcripts in inline markup that are scored as a separate set and never
used for tuning. The eight files here (`u01` to `u08`) and `denylist.yaml` were generated by a
coding agent that saw only the inline-markup format, not the detectors, templates or other
sets. They stand in for a set in your own phrasing: replace or extend them with transcripts
you write yourself, since your phrasing is what the numbers should reflect.

Format:

- One `.txt` file per transcript, using inline markup for sensitive spans (format:
  `docs/eval-format.md`, section 2):

  ```text
  [[PERSON:Orla Venkatesh]]: Morning. Is [[PERSON#bram:Bram]] joining?
  [[PERSON#bram:Bram Okafor]]: Yes. The [[CLIENT:Quillfeather]] deal closed at [[AMOUNT:$42,000]].
  ```

- Optional `denylist.yaml` in this folder: the deny-list to use for these transcripts.
- Never put real names, companies, numbers or transcripts here.

Run: `offrecord eval --set user` (or `offrecord eval` for all sets side by side).

Real transcripts never go in this folder. To measure offrecord on your own real calls, keep
them in a private folder outside the repository and follow `docs/private-eval.md`.
