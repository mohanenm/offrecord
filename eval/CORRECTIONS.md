# Corrections log

Every change to a label in an evaluation set is recorded here: which set and item, what changed,
why, and whether it raised or lowered the score. The point is that corrections cannot only
flatter the results. Held-out labels may be corrected only for genuine labelling bugs, never to
match detector output.
